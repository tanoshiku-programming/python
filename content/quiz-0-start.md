@@ quiz:ch0
::: q
画面に「こんにちは！」と表示する1行を書くと？
:::
::: a
`print("こんにちは！")` です。Scratchの「（こんにちは！）と言う」ブロックと同じです。
:::

::: q
プログラムの中で、日本語を書いていいのはどこ？
:::
::: a
`" "` で囲んだ文字の中です（それと `#` のコメント）。`print` やかっこ、`"` は半角で書きます。
:::

@@ quiz:ch9
::: q
この教室で使う2つのエディタの名前は？
:::
::: a
**IDLE**（アイドル）と **VS Code**（ブイエスコード）です。どちらで書いても、Pythonのプログラムは同じように動きます。

::: q
「動かない」「エラーが出た」ときに、最初に読むのは、エラーメッセージのどこ？
:::
::: a
**いちばん下の行**です。何が起きたかが書いてあります。そのあと、`line 〇` の行番号の行を見直します。
:::

@@ quiz:editor
::: q
Pythonをインストールすると、いっしょに入ってくるエディタはどっち？
:::
::: a
**IDLE** です。何も追加しなくても、すぐに使えます。

:::

@@ quiz:shell
::: q
シェル（`>>>` の画面）で `1 + 2` と打つと `3` と出た。同じ `1 + 2` をファイルに書いて実行すると、どうなる？
:::
::: a
**何も表示されません**。ファイルのプログラムでは、`print(1 + 2)` と書いて表示します。
:::

::: q
`>>>` は、自分で打つもの？
:::
::: a
**打ちません**。`>>>` は「命令をどうぞ」という、Pythonが出している合図（プロンプト）です。
:::

@@ quiz:pyfile
::: q
Pythonのプログラムのファイル名の、最後につける拡張子は？
:::
::: a
`.py` です。`game.py` のようにつけます。
:::

::: q
ゲームでサイコロを使うので、ファイル名を `random.py` にした。何がまずい？
:::
::: a
`import random` をしたときに、Pythonの本物の random ではなく、**自分のファイルが読みこまれてしまいます**。`saikoro.py` など、別の名前にしよう。
:::

::: q
次のうち、ファイル名としていちばんよいものは？（`ゲーム 1.py`、`game 1.py`、`game1.py`）
:::
::: a
`game1.py` です。日本語やスペースは入れないようにします。
:::

@@ quiz:terminal
::: q
Pyxelをインストールするコマンドは？
:::
::: a
`pip install pyxel` です。ターミナルで打ちます。
:::

::: q
IDLE の `>>>` のシェルに `pip install pyxel` と打ったら、エラーになった。なぜ？
:::
::: a
`pip` は Python の命令ではなく、**ターミナルで打つコマンド**だからです。ターミナルを開いて打ちます。
:::

@@ quiz:trouble
::: q
次のプログラムは、見た目は正しそうなのにエラーになった。原因は？
```python norun
print（"こんにちは"）
```
:::
::: a
かっこが**全角**の `（ ）` になっています。半角の `( )` に直します。日本語を書いていいのは、`" "` の中とコメントだけです。
:::

::: q
次のプログラムは、どこがまちがっている？
```python norun
Print("こんにちは")
```
:::
::: a
`Print` の `P` が大文字です。正しくは `print` です。Pythonは、大文字と小文字を区別します。
:::

::: q
エラーの行を見ても、間違いが見つからない。次にどこを見るといい？
:::
::: a
**1つ上の行**です。かっこの閉じ忘れなどは、次の行でエラーとして見つかることがあります。
:::
