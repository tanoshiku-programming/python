@@ quiz:ch8
::: q
クラスとインスタンスを、たい焼きにたとえると？
:::
::: a
クラスは**たい焼きの型**（設計図）、インスタンスは**焼いたたい焼き**（実物）です。1つの型から、たい焼きはいくつでも焼けます。
:::

::: q
クラスを使って Pyxel のプログラムを書くと、7章の書き方で必要だった何が、いらなくなる？
:::
::: a
`global` です。変数を `self.x` のように書くので、`update` でも `draw` でもそのまま使えます。
:::

@@ quiz:class
::: q
次のプログラムを実行すると、何が表示される？
```python hideout
class Neko:
    def __init__(self, namae):
        self.namae = namae


a = Neko("タマ")
b = Neko("ミケ")
print(b.namae)
```
:::
::: a
`b` は「ミケ」という名前で作ったインスタンスです。
:::

::: q
クラスの名前は、ふつう何の文字で始める？
:::
::: a
**大文字**です（`Hiyoko`、`App` など）。Pythonのきまりで、大文字で始まっていれば「これはクラスだな」と分かります。
:::

::: q
`pyxel.sounds[0]` は、何というクラスから作られたオブジェクト？
:::
::: a
`Sound` クラスです。Pyxelを作った人が用意した設計図から作られています。
:::

::: q
「オブジェクト指向」と「オブジェクト」は、同じ意味？
:::
::: a
**ちがいます**。オブジェクト指向は「データと命令を1つのモノにまとめて考える」**考え方**で、オブジェクトは、その考え方でできた**モノ（部品）**です。
:::

@@ quiz:init-self
::: q
`__init__` は、いつ動く？
:::
::: a
`Hiyoko()` のように、**インスタンスを作った瞬間に、自動で1回だけ**動きます。
:::

::: q
クラスの中の `self.genki` は、どんな意味？
:::
::: a
「**自分の** `genki`」という意味です。インスタンスごとに、別々の値を持っています。
:::

::: q
次のプログラムを実行すると、何が表示される？
```python hideout
class Hiyoko:
    def __init__(self):
        self.genki = 3


a = Hiyoko()
b = Hiyoko()
a.genki = 10
print(a.genki, b.genki)
```
:::
::: a
`a` の元気だけを10にしたので、`b` は3のままです。
:::

@@ quiz:method
::: q
次のプログラムを実行すると、何が表示される？
```python hideout
class Counter:
    def __init__(self):
        self.kazu = 0

    def tasu(self):
        self.kazu = self.kazu + 1


c = Counter()
c.tasu()
c.tasu()
print(c.kazu)
```
:::
::: a
`tasu` を2回呼んだので、`kazu` は `2` になります。
:::

::: q
`kudamono_list.append("ぶどう")` の `append` は、何の仲間？
:::
::: a
**メソッド**です。リストというオブジェクトが持っている機能を、`.` でつないで呼び出しています。
:::

@@ quiz:pyxel-class
::: q
クラスで書いたPyxelのプログラムで、`run` はどう書く？
:::
::: a
`pyxel.run(self.update, self.draw)` です。`update` と `draw` は App のメソッドなので、`self.` をつけます。
:::

::: q
クラスの形で書いたのに、実行しても何も起きなかった。いちばん最後に何を書き忘れている？
:::
::: a
`App()` です。設計図（クラス）を作っただけでは動かないので、インスタンスを作って `__init__` を動かします。
:::

@@ quiz:class-catch
::: q
クラス版のほしキャッチで、ほしを上に戻す処理は、どこにまとめた？
:::
::: a
`Hoshi` クラスの `modoru` メソッドです。受け止めたときも、落としたときも、`self.hoshi.modoru()` の1行で戻せます。
:::

::: q
ゲームに敵を足したくなった。クラスの考え方では、まず何を作る？
:::
::: a
敵のクラス（たとえば `Teki`）です。敵の「変数（位置など）」と「すること（動く・描く）」をセットにして書きます。
:::

@@ quiz:class-many
::: q
雪を40個ふらせるとき、クラス版では雪をどうやって覚えておく？
:::
::: a
`Yuki` のインスタンスを40個作って、**1本のリスト**（`self.yuki_list`）に入れておきます。
:::

::: q
`for yuki in self.yuki_list:` の `yuki` には、何が入る？
:::
::: a
雪の**インスタンス**が1つずつ入ります。だから `yuki.ugoku()` のように、その雪のメソッドを呼べます。
:::
