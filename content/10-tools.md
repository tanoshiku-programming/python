## この章の使い方
この章は、**最初から順番に読まなくて大丈夫**です。「動かない」「この画面は何？」と思ったときに開いて、必要なところだけ読もう。

プログラムは、**エディタ**という「プログラムを書くためのソフト」で書きます。この教室では、**IDLE**（アイドル）と **VS Code**（ブイエスコード）の2つを使います。細かい使い方（どのボタンを押すか）は、授業で画面を見ながら教わります。ここには、**知っておくと困らないこと**をまとめています。

- [[editor]]：IDLE と VS Code のちがい
- [[shell]]：`>>>` の画面と、ファイルに書くプログラムのちがい
- [[pyfile]]：ファイルの名前と保存場所
- [[terminal]]：ターミナルと、`pip install`
- [[trouble]]：困ったときに見るページ

::: point
どちらのエディタを使っても、このサイトのプログラムは**同じように動きます**。書くプログラムは同じで、ちがうのは「書く場所」と「実行のしかた」だけです。
:::

## 困ったら、まずここ

## エディタってなに？
**エディタ**は、プログラムを書くためのソフトです。文字を書くだけならメモ帳でもできますが、エディタには、

- 命令に色がついて、間違いに気づきやすい
- [[indent]]（行の頭の空白）を自動でそろえてくれる
- 書いたプログラムを、すぐに実行できる

といった、プログラムを書くのに便利な機能があります。

## IDLE（アイドル）
**Pythonをインストールすると、いっしょに入ってくる**エディタです。Pythonを使える状態なら、何も追加しなくてもすぐ使えます。

- 開くと、まず `>>>` が出る画面（**シェル**）が出る（[[shell]]）
- 「New File（新しいファイル）」で、プログラムを書くための別の画面を開く
- 書いたら**保存**してから実行する（実行は F5 キー）
- 実行した結果や `input()` の入力は、`>>>` のシェルの画面に出る

できることがしぼられていて**シンプル**なので、初めてのテキストプログラミングにぴったりです。

## VS Code（ブイエスコード）
**Visual Studio Code**（ビジュアル・スタジオ・コード）の略で、世界中で人気のエディタです。Pythonだけでなく、HTML や JavaScript など、**いろいろなプログラミング言語に使えます**。

- Pythonで使うには、「Python」の**拡張機能**（あとから足す機能）を入れる
- **フォルダを開いて**、その中にファイルを作って使う
- 実行すると、画面の下の**ターミナル**に結果が出る（[[terminal]]）
- 入力のおすすめ（補完）や、間違いの指摘など、便利な機能がたくさんある

機能が多いぶん、最初は「フォルダ」「ファイル」「拡張子」の考え方に慣れる必要があります（[[pyfile]]）。

## くらべてみよう
| | IDLE | VS Code |
| --- | --- | --- |
| 手に入れ方 | Pythonといっしょに入っている | 別にインストールする |
| 使える言語 | Pythonだけ | いろいろな言語 |
| 見た目 | シンプル | 機能が多い |
| 結果が出る場所 | `>>>` のシェルの画面 | 下のターミナル |
| 実行のしかた | 保存して F5 | 保存して ▷（実行）ボタン |
| 止め方 | Ctrl + C、または閉じる | ターミナルで Ctrl + C |
| 向いている人 | テキストのプログラミングが初めての人 | HTMLなどで使ったことがある人、慣れてきた人 |

::: point
どちらを使っても、Pythonそのものは同じです。IDLE で書いたプログラムは、そのまま VS Code でも動きます。IDLE で慣れたら、VS Code に進むのがおすすめです。
:::

::: stuck
Mac のノートパソコンでは、F5 キーを押すときに **fn キーもいっしょに**押す必要があることがあります。
:::

::: deep プロはどんなエディタを使っているの？
仕事でプログラムを書く人も、VS Code を使っている人がとても多いです。ほかにも PyCharm（パイチャーム）など、Python用のエディタもあります。どれを使っても、書く Python は同じです。
:::

## 2つの書き方
Pythonには、プログラムを動かす方法が2つあります。

| | シェル（`>>>` の画面） | ファイル（.py） |
| --- | --- | --- |
| 書き方 | 1行書いて Enter を押すと、すぐ動く | 何行も書いて、保存してから実行する |
| 残るか | 閉じると消える | 保存されて、あとで直せる |
| 向いていること | ちょっと試す、計算機のように使う | ちゃんとしたプログラムを作る |

IDLE を開いたときに出る、`>>>` が並んだ画面が**シェル**です。`>>>` は「どうぞ、命令を書いてください」という合図で、**プロンプト**といいます。

## シェルでは、print がなくても表示される
シェルで `1 + 2` と打って Enter を押すと、`3` と表示されます。

```output
>>> 1 + 2
3
>>> "Py" + "thon"
'Python'
```
ところが、**ファイルに `1 + 2` とだけ書いて実行しても、何も表示されません。**

```python
1 + 2
```
シェルは「答えを見せてくれるサービス」をしてくれますが、ファイルのプログラムでは、表示したいものは**必ず [[print]] で表示**します。

```python
print(1 + 2)
```

::: point
シェルで試したときは表示されたのに、ファイルに書くと表示されない。そんなときは、`print()` を忘れていないか確かめよう。
:::

## よくある間違い
- **`>>>` までコピーしない**：`>>>` はPythonが出している合図です。自分で打つものではありません
- **何行もあるプログラムを、シェルに貼りつけない**：シェルは1つずつ実行する場所なので、エラーになることがあります。何行もあるプログラムは、ファイルに書こう
- **シェルの画面に書いたものは保存されない**：あとで使うプログラムは、ファイルに書いて保存しよう

::: deep VS Code でもシェルは使える
VS Code のターミナルで `python`（Mac では `python3`）と打つと、同じ `>>>` のシェルが始まります。終わるときは `exit()` と打ちます。
:::

## .py は「Pythonのファイルです」という印
ファイルの名前の最後にある `.py` を、**拡張子**（かくちょうし）といいます。パソコンは、拡張子を見て「これは何のファイルか」を判断します。

| 拡張子 | 何のファイル？ |
| --- | --- |
| `.py` | Pythonのプログラム |
| `.html` | Webページ |
| `.png` | 画像 |
| `.txt` | ただの文字（メモ） |

Pythonのプログラムは、`game.py` や `uranai.py` のように、最後に `.py` をつけて保存します。

::: stuck
パソコンの設定によっては、拡張子が**見えないように**なっています。ファイルが `game` に見えても、本当は `game.py` だったり、`game.py.txt` になってしまっていたりします。おかしいと思ったら、先生に確かめてもらおう。
:::

## ファイル名のつけ方
| ルール | よい例 | よくない例 |
| --- | --- | --- |
| 半角の英数字と `_` を使う | `game1.py`、`hoshi_catch.py` | `ゲーム.py` |
| 空白（スペース）を入れない | `my_game.py` | `my game.py` |
| Pythonのモジュールと同じ名前にしない | `my_random.py` | `random.py`、`pyxel.py` |

最後のルールは、とくに大事です。`random.py` という名前で保存すると、`import random` をしたときに、Pythonに入っている本物の[[random]]ではなく、**自分のファイルが読みこまれてしまいます**。

```output
AttributeError: module 'random' has no attribute 'randint'
```
こんなエラーが出たら、自分のファイルの名前が `random.py` になっていないか確かめよう（[[module]]）。`pyxel.py` や `calendar.py`、`math.py` も同じです。

## 保存する場所
- 自分の**フォルダ**を1つ決めて、そこにまとめて保存しよう
- Pyxelで使うフォントファイル（[[pyxel-jp]]）や画像のファイルは、**プログラムと同じフォルダ**に置きます

::: stuck
Pyxelは、`pyxel.init()` のあとは、**プログラム（.py）があるフォルダ**からファイルを探してくれます。だから、フォントや画像は、プログラムと同じフォルダに置いておけば、IDLE でも VS Code でも見つかります。`Failed to open file '…'`（ファイルを開けません）や `FileNotFoundError`（ファイルが見つかりません）が出たら、ファイルが本当に同じフォルダにあるか、ファイル名のつづり（`.png` や `.bdf` まで）が合っているかを確かめよう。
:::

## 絶対パスと相対パス
画像やフォントの場所を、文字で書いたものを**パス**といいます。書き方や、「今いる場所」の考え方は、[[path]]で説明しています。

## 保存してから実行
エディタで書き直したのに、結果が変わらない。そんなときは、**保存し忘れ**かもしれません。IDLE は、保存していないと実行する前に「保存しますか？」と聞いてきます。VS Code は、タブの名前の横に `●` が出ているときは、まだ保存されていません。

## pip：モジュールを追加する
[[pyxel]]のように、Pythonに最初から入っていないモジュールは、`pip`（ピップ）というコマンドで追加します。ターミナルで、次のように打ちます。

```bash
pip install pyxel
```
インストールは、パソコン1台につき**1回だけ**でOKです。

::: stuck

:::

::: stuck

| パソコン | 打ち方 |
| --- | --- |
| Mac | `pip3 install pyxel` |
| Windows | `py -m pip install pyxel` |
:::

| `pyxel copy_examples` | Pyxelの見本とフォントをコピーする（[[pyxel-jp]]） |
| `pyxel edit ファイル名.pyxres` | ドット絵や音を作る Pyxel Editor を開く（[[px-load]]） |

::: deep IDLE を使っていても、ターミナルは使う
IDLE だけでPythonを書いている人も、`pip install` をするときだけはターミナルを使います。インストールが終われば、あとは IDLE だけでPyxelのプログラムを書いて、F5 で実行できます。
:::

## まずは、ここを確かめよう
1. **エラーメッセージのいちばん下の行**を読む（[[error]]）
2. `line 3` のような**行の番号**を見て、その行と、**その1つ上の行**を見直す
3. **保存**してから実行したか確かめる（[[pyfile]]）

## 全角の文字がまざっている
いちばん多い原因です。Pythonの命令や記号は、**半角**で書きます。日本語入力がオンのまま書くと、見た目はそっくりな**全角**の文字が入ってしまいます。

```python error
print（"こんにちは"）
```
`invalid character '（'` は「使えない文字（全角のかっこ）がある」という意味です。見分けにくいものには、次のようなものがあります。

| 全角（間違い） | 半角（正しい） |
| --- | --- |
| `（ ）` | `( )` |
| `”　“` | `"` |
| `：` | `:` |
| `＝` | `=` |
| 全角スペース | 半角スペース |

::: point
**日本語を書いていいのは、`" "` の中と、`#` のコメントだけ**。それ以外を書くときは、日本語入力をオフにしよう。
:::

全角スペースは目に見えないので、とくに気づきにくいです。

```python error
x　= 5
```
`invalid non-printable character U+3000` と出たら、その行のどこかに全角スペースがあります（この例では `x` と `=` のあいだ）。行の最後や、行の頭も確かめよう。

## 大文字と小文字がちがう
Pythonは、大文字と小文字を**別の文字**として扱います。

```python error
Print("こんにちは")
```
`Print` ではなく `print` です。新しいPythonでは、`Did you mean: 'print'?`（`print` のことですか？）とヒントが出ることもあります。反対に、[[bool]]の `True` と `False` は、先頭が大文字です。

## かっこ・" の閉じ忘れ
```python error
print("こんにちは"
```
`'(' was never closed` は「`(` が閉じられていない」という意味です。

```python error
print("こんにちは)
```
`unterminated string literal` は「文字の `"` が閉じられていない」という意味です。

::: stuck
かっこの閉じ忘れは、エラーが**次の行**で見つかることがあります。エラーの行を見ても正しいときは、**1つ上の行**を確かめよう。
:::

## : の書き忘れ
[[if]]・[[for]]・[[while]]・[[function]]（`def`）の行の最後には、`:` が必要です。

```python error
x = 5
if x > 3
    print("大きい")
```
`expected ':'` は「`:` があるはずなのに、ない」という意味です。

## 行の頭の空白がずれている
```python error
x = 5
if x > 3:
print("大きい")
```
`expected an indented block` は「ここは行の頭を下げてね」という意味です。詳しくは[[indent]]を見よう。

## 何も表示されない
- **`print()` を書いていない**：シェルでは表示されても、ファイルでは `print` が必要です（[[shell]]）
- **関数を呼び出していない**：`def` で作っただけでは動きません（[[function]]）
- **if の条件に当てはまっていない**：条件が `False` だと、中は実行されません（[[if]]）

## 数を入力したのに、計算がおかしい
`input()` で受け取ったものは、数字に見えても**文字**です。`int()` で数に変えよう（[[input]]・[[typeconv]]）。

```python in=5
n = input("数：")
print(n * 2)
```
`10` ではなく `55` になりました。

## 止まらない
[[infinite-loop]]になっているかもしれません。**Ctrl キーを押しながら C キー**を押すと止まります。Pyxelのプログラムは、**ESC キー**で止まります。

## Pyxel が動かない
| エラー | 原因 | 直し方 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'pyxel'` | Pyxelがインストールされていない | ターミナルで `pip install pyxel`（[[terminal]]） |
| `Failed to open file '…'`（Pyxelの命令）、`FileNotFoundError`（ふつうのPython） | フォントや画像などのファイルが見つからない | プログラムと同じフォルダに置く。名前のつづりも確かめる（[[pyfile]]） |
| `UnboundLocalError` | `global` を書き忘れた | `update` の先頭に `global 変数名`（[[update-draw]]） |
| `AttributeError: module 'pyxel' has no attribute …` | 自分のファイル名が `pyxel.py` | ファイル名を変える（[[pyfile]]） |

::: stuck
もらった画像やフォントが **zip ファイル**に入っているときは、使う前に必ず**展開**しよう。zip の中のファイルは、中身が見えていても、まだパソコン上の本物のファイルになっていないので、プログラムから見つけられません。展開してできたファイルを、プログラムと同じフォルダに置きます。
:::

::: point
それでも分からないときは、**エラーメッセージのいちばん下の行**を先生に見せよう。「どこで」「何が」起きたかが書いてあるので、すぐに原因が分かります。
:::

## ファイルの場所を、文字で書く
プログラムで画像やフォントを読みこむとき、`"image.png"` のように、**ファイルの名前**を書きます。ファイルを探すためには、「どこにあるか」も必要です。この「場所」を文字で書いたものを、**パス**といいます。

フォルダは、フォルダの中にフォルダが入っていて、木の枝のような形になっています。

```
デスクトップ
└── ゲーム制作
    └── hiyoko
        ├── main.py
        ├── hiyoko.pyxres
        └── gazou
            └── tori.png
```

## 絶対パスと相対パス
パスの書き方は、2種類あります。

| | 書き方 | 例 |
| --- | --- | --- |
| **絶対パス** | いちばん上から、全部書く | Mac：`/Users/hanako/Desktop/ゲーム制作/hiyoko/main.py`<br>Windows：`C:\Users\hanako\Desktop\ゲーム制作\hiyoko\main.py` |
| **相対パス** | **今いる場所**から書く | `hiyoko.pyxres`、`gazou/tori.png` |

絶対パスは、住所を「県・市・町・番地」と全部書くようなものです。相対パスは、「となりの家」「2軒先」のように、**今いる場所からの行き方**だけを書きます。

| 相対パス | 意味 |
| --- | --- |
| `hiyoko.pyxres` | 今いるフォルダの中の `hiyoko.pyxres` |
| `gazou/tori.png` | 今いるフォルダの中の、`gazou` フォルダの中の `tori.png` |
| `../memo.txt` | 1つ**上**のフォルダの `memo.txt` |

`..`（ドット2つ）は「1つ上のフォルダ」、`/` はフォルダの区切りです。

## 「今いる場所」ってどこ？
相対パスで大事なのは、**今いる場所**がどこか、です。これを**カレントディレクトリ**ともいいます（ディレクトリはフォルダのことです）。`os.getcwd()` で調べられます。

```python norun
import os
print(os.getcwd())
```
```output
/Users/hanako/Desktop/ゲーム制作/hiyoko
```
`getcwd` は **get current working directory**（今の作業フォルダを手に入れる）の略です。

::: point
ふつうのPythonのプログラムは、「今いる場所」が、**実行のしかたで変わる**ことがあります。たとえば、ターミナルで `python main.py` と打つと、**ターミナルが今いるフォルダ**が基準になります。
:::

## Pyxelは、プログラムのある場所から探す
[[pyxel]]を使うときは、`pyxel.init()` のあと、Pyxelが「今いる場所」を、**プログラム（.py）があるフォルダ**に切り替えてくれます。だから、絵や音のファイルは、**プログラムと同じフォルダ**に置いて、`"hiyoko.pyxres"` のように名前だけ書けば、どこから実行しても見つかります（[[pyfile]]）。

ただし、ふつうのPythonで `open("memo.txt")` のようにファイルを読むときは、切り替えてくれません。見つからないときは、`FileNotFoundError`（ファイルが見つかりません）になります。

## Windowsの `\` の注意
Windowsのパスは、`C:\Users\hanako\…` のように `\`（円マーク、またはバックスラッシュ）で区切ります。でもPythonの文字列では、`\` は特別な意味（`\n` は改行）をもつので、そのまま書くとまちがいのもとです。**Windowsでも、`/` で区切って書けます**（`"gazou/tori.png"`）。迷ったら、`/` で書こう。

::: stuck
絶対パスをプログラムに書くと、**友だちのパソコンでは動きません**（フォルダの名前がちがうからです）。ゲームを配るときは、相対パスで書いて、ファイルをまとめて渡そう（[[game-package]]）。
:::

**相対パス**です。絶対パスは自分のパソコンのフォルダの名前を書いているので、友だちのパソコンでは見つからなくなります。
