## Pythonってなに？
Scratchでは、ブロックをつなげてプログラムを作りました。Pythonでは、同じことを**文字で書きます**。

::: scratch
Scratchの「（こんにちは！）と言う」ブロックは、Pythonでは `print("こんにちは！")` と書きます。「もし〜なら」も「〇回繰り返す」も「変数」も、Pythonにちゃんとあります。Scratchでやってきたことは、全部そのまま役に立ちます。
:::

## どこに書くの？
**IDLE**（アイドル）か **VS Code**（ブイエスコード）というソフトに書きます。どちらを使うかと、使い方は、授業で教わります。どちらで書いても、Pythonは同じように動きます。

## 1行、動かしてみよう
```python
print("こんにちは！")
```
画面に `こんにちは！` と出たら成功です。これで、あなたもPythonのプログラムを動かせました。

::: point
`print` や `( )` や `"` は、**半角**で書きます。日本語を書いていいのは、`" "` の中だけです。日本語入力はオフにしてから書こう。
:::
