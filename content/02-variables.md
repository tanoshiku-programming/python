## この章のゴール
**変数**と**リスト**は、どちらも「データをしまう入れ物」です。1つだけしまうなら変数、まとめてしまうならリスト。ちがいは、それだけです。

| 入れ物 | しまえる数 | 例 |
| --- | --- | --- |
| 変数 | 1つ | `score = 80` |
| リスト | いくつでも | `tensuu_list = [70, 85, 90]` |

### まずはこれ（この順番で読もう）
1. [[variable]]：値に名前をつけて、しまっておく
2. [[assignment]]：= で入れる、+= で増やす
3. [[list]]：たくさんの値を、まとめてしまう
4. [[list-index]]：リストの何番目かを取り出す（0から数える）

ほかの言葉は「必要になったら」のページです。最初は飛ばして大丈夫です。ページのいちばん下に、一覧があります。

::: point この章で、自分でできるようになること
- □ 変数を作って、値を入れたり、入れ直したりできる
- □ `score += 1` で、変数を増やせる
- □ リストを作って、`[0]` で取り出せる（0から数える）
- □ `append` で、リストに足せる

ゲームを作る前に、ここにあることを、**お手本を見ないで書けるように**、くりかえし練習しよう。
:::

## やってみよう
::: try 3教科の合計
国語・数学・理科の点数をリストに入れて、合計を表示しましょう。
:::
::: answer
```python
tensuu_list = [70, 85, 90]
print(sum(tensuu_list))
```
`sum()` は、リストの合計を出す関数です。[[for]]文で1つずつ足していく方法もあります。
:::

::: try 好きな食べ物を3つ
好きな食べ物を3つ入れたリストを作り、2番目のものだけ表示しましょう。
:::
::: answer
```python
tabemono_list = ["カレー", "すし", "ラーメン"]
print(tabemono_list[1])
```
「2番目」は、番号では `1` です。0から数えるのがポイントです。
:::

reads: ==イコール | type=タイプ
group: まずはこれ
--
::: scratch
Scratchの「変数を作る」と同じです。「（score）を（0）にする」は、Pythonでは `score = 0` と書きます。Scratchでは先にボタンで変数を作りましたが、Pythonでは**値を入れたときに変数ができます**。
:::

## 書き方のかたち
::: tpl 変数の作り方
〔変数名〕 = 〔入れる値〕

| 〔変数名〕 | 自分で決める名前（score, name など） |
| 〔入れる値〕 | 数、文字、リストなど、入れたいもの |
:::

::: flow variable 変数は「名前つきの箱」
:::

## 入れ物のイメージ
変数は、名前のついた箱です。値を入れておいて、名前を呼べば取り出せます。

```python
x = 10
print(x)
x = x + 5
print(x)
```
`x = 10` で、箱 `x` に `10` が入ります。`x = x + 5` は、先に右側を計算（`10 + 5`）してから、結果を `x` に入れ直しています（[[assignment]]）。

## 名前のつけ方
| ルール | 例 |
| --- | --- |
| 半角の英数字と `_` が使える | `score`、`nedan`、`tensuu_list` |
| 数字で始められない | `1ban` はNG、`ichiban` はOK |
| `if` や `for` など、Pythonの言葉は使えない | `if = 3` はNG |
| 大文字と小文字は別の名前 | `Name` と `name` はちがう |

何が入っているか分かる名前をつけると、あとで読みやすくなります。英語でもローマ字でもOKです。このサイトでのつけ方は[[naming]]にまとめています。

::: deep 入れた値の型
入れた値によって、[[datatype]]が決まります。

```python
a = 10
b = "10"
print(type(a))
print(type(b))
```
:::

## 作る前には使えない
```python error
print(total)
```
`total` に値を入れる前に使おうとしたので、[[error]]（NameError）です。

@@ assignment
title: 代入
type: 書き方
chapter: 2
syntax: 変数 = 値
summary: = を使って、変数に値を入れることです。算数の「等しい」とは意味がちがいます。
reads: ==イコール | +==プラスイコール | -==マイナスイコール
group: まずはこれ
--
::: scratch
Scratchの「（score）を（0）にする」が `score = 0`、「（score）を（1）ずつ変える」が `score += 1` です。
:::

## 書き方のかたち
::: tpl 代入の書き方
〔変数名〕 = 〔値や計算〕

| 〔変数名〕 | 右の答えを入れる、入れ物の名前 |
| 〔値や計算〕 | 先に右がわが計算されて、その答えが左に入る |
:::

## = は「入れる」
`=` は、右の値を、左の[[variable]]に入れる記号です。「等しい」ではありません。

```python
count = 0
count = count + 1
count = count + 1
print(count)
```
`count = count + 1` は、算数だとおかしな式ですが、プログラムでは「今の `count` に1を足して、`count` に入れ直す」という意味です。

## 短く書く
```python
count = 0
count += 1
count += 1
print(count)
```
| 書き方 | 意味 |
| --- | --- |
| `a += 5` | `a = a + 5`（Scratchの「（a）を（5）ずつ変える」） |
| `a -= 5` | `a = a - 5` |
| `a *= 5` | `a = a * 5` |
| `a /= 5` | `a = a / 5` |
| `a //= 5` | `a = a // 5` |
| `a %= 5` | `a = a % 5` |

このような書き方を、**累算代入**（るいさんだいにゅう）といいます。「今の値に、計算した結果を入れ直す」ときの短い書き方です。

::: deep 同時に代入する
```python
a, b = 1, 2
a, b = b, a
print(a, b)
```
2行目は、`a` と `b` の中身を入れ替えています。
:::

::: stuck
「等しいかどうか」を調べるときは、`=` ではなく `==` を使います（[[comparison]]）。
:::

@@ list
title: リスト
type: データ型
chapter: 2
syntax: [値1, 値2, 値3]
summary: たくさんの値を、順番にまとめて入れておく入れ物です。[ ] で書きます。
reads: list=リスト | append=アペンド | remove=リムーブ | len=レン | sum=サム | max=マックス | min=ミン
group: まずはこれ
--
::: scratch
Scratchの「リストを作る」と同じです。「（ぶどう）を（くだもの）に追加する」は `append`、「（くだもの）の長さ」は `len()` です。ただし、Pythonのリストは、番号を**0から**数えます（Scratchは1からでした）。
:::

## 書き方のかたち
::: tpl リストの作り方
〔リスト名〕 = [〔1つ目〕, 〔2つ目〕, 〔3つ目〕]

| 〔リスト名〕 | リスト全体につける名前 |
| 〔1つ目〕 | 中に入れる値。カンマ , で区切って、いくつでも並べられる |
:::

## 作る
```python
kudamono_list = ["りんご", "みかん", "バナナ"]
kazu_list = [10, 20, 30]
kara_list = []
print(kudamono_list)
```
値を `,` で区切って、`[ ]` で囲みます。中身は数でも文字でも入れられます。

## 取り出す
```python
kudamono_list = ["りんご", "みかん", "バナナ"]
print(kudamono_list[0])
print(kudamono_list[2])
```
何番目かを表す番号を[[list-index]]といいます。**0から数える**ので注意してください。

## 変える・増やす・減らす
```python
tensuu_list = [70, 85, 90]
tensuu_list[0] = 75
tensuu_list.append(100)
tensuu_list.remove(85)
print(tensuu_list)
```
- `tensuu_list[0] = 75`：0番目を入れ替える
- `append(値)`：最後に足す
- `remove(値)`：その値を消す

## 長さと集計
```python
tensuu_list = [75, 90, 100]
print(len(tensuu_list))
print(sum(tensuu_list), max(tensuu_list), min(tensuu_list))
```
`len` は個数、`sum` は合計、`max` は最大、`min` は最小です。

::: deep 便利な命令
```python
kazu_list = [30, 10, 20]
kazu_list.sort()
print(kazu_list)
kazu_list.sort(reverse=True)
print(kazu_list)
saigo = kazu_list.pop()
print(saigo, kazu_list)
kazu_list.clear()
print(kazu_list)
```
| 命令 | すること |
| --- | --- |
| `sort()` | 小さい順に並べかえる（`reverse=True` で大きい順） |
| `pop()` | 最後の1つを取り出す（リストからはなくなる） |
| `clear()` | 中身を全部消して、空っぽにする |
| `remove(値)` | その値を1つ消す |
:::

## 全部に同じことをする
[[for]]文と組み合わせると、リストの中身を1つずつ使えます。

```python
for ten in [75, 90, 100]:
    print(ten)
```

::: stuck
リストの長さより大きい番号を指定すると、[[error]]になります。

```python error
kudamono_list = ["りんご", "みかん", "バナナ"]
print(kudamono_list[3])
```
3つしかないので、番号は `0`、`1`、`2` までです。
:::

@@ list-index
title: インデックス（添字）
type: 考え方

summary: リストや文字列で、「何番目か」を表す番号です。0から数えます。

group: まずはこれ
--
## 書き方のかたち
::: tpl 取り出し方
〔リスト名〕[〔番号〕]

| 〔リスト名〕 | 取り出したいリストの名前 |
| 〔番号〕 | 0 から数える。うしろからは -1, -2 … |
:::

::: flow listidx 番号は 0 から。うしろからは -1 から
:::

## 0から数える
```python
kudamono_list = ["りんご", "みかん", "バナナ"]
print(kudamono_list[0])
print(kudamono_list[2])
```
| 番号 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 中身 | りんご | みかん | バナナ |

「1番目」が `0` なので、慣れないうちは混乱しやすいです。「何個目か」ではなく「先頭から何個進んだか」と考えると覚えやすくなります。先頭の「りんご」は、先頭から0個進んだところにあるので `0` です。

::: scratch
Scratchのリストは1番目から数えたので、「（くだもの）の（1）番目」が先頭でした。Pythonでは先頭は `kudamono_list[0]` です。
:::

## うしろから数える
マイナスの番号を使うと、うしろから数えられます。

```python
kudamono_list = ["りんご", "みかん", "バナナ"]
print(kudamono_list[-1])
print(kudamono_list[-2])
```
`-1` が最後、`-2` が最後から2つ目です。

::: deep 範囲をとりだす（スライス）
```python
kudamono_list = ["りんご", "みかん", "バナナ", "ぶどう"]
print(kudamono_list[0:2])
print(kudamono_list[1:])
```
`[始め:終わり]` で、始めから終わりの1つ手前までを取り出します。終わりの番号は**含みません**。`[1:]` のように終わりを書かないと、最後までになります。
:::

## 文字列でも使える
[[str]]でも、同じように番号で取り出せます。

```python
print("Python"[0])
```

::: stuck
範囲の外の番号を指定すると `IndexError` です（[[error]]、[[list]]）。
:::

::: scratch
Scratchでは、変数の名前を「てんすう」のように日本語でつけられました。Pythonでも、名前は自分で決めます。ただし、使える文字にきまりがあるので、このサイトではローマ字で書いています。
:::

## プログラムに出てくる3種類の言葉
プログラムを読むと、いろいろな英単語が出てきます。でも、じつは**3種類**に分けられます。

```python
nedan = 120
kosuu = 3
if kosuu >= 3:
    print(nedan * kosuu)
```
| 種類 | このプログラムでは | だれが決めた？ |
| --- | --- | --- |
| ① Pythonの決まった言葉 | `if` | Python（変えられない） |
| ② Pythonが用意した関数 | `print` | Python（そのまま使う） |
| ③ **自分でつけた名前** | `nedan`、`kosuu` | **プログラムを書いた人** |

`nedan` や `kosuu` は、プログラムを書いた人が自由に決めた名前です。`hako` でも `a` でも、同じように動きます。

::: point
**見分けるコツ**：このサイトのプログラムでは、①と②の言葉の多くは**クリックできます**（説明のページに飛べます）。③の自分でつけた名前は、クリックできません。エディタでも、①と②には色がつくことが多いです。
:::

## このサイトの名前のつけ方
英語の名前は、知らない単語だと「これはPythonの命令？ それとも自分でつけた名前？」と迷ってしまいます。そこでこのサイトでは、次のルールで名前をつけています。

| ルール | 例 |
| --- | --- |
| カタカナで知っている英語は、そのまま使う | `score`（スコア）、`name`（ネーム）、`count`（カウント）、`total`（トータル） |
| それ以外は、ローマ字で書く | `nedan`（値段）、`tensuu`（点数）、`kekka`（結果）、`kion`（気温） |
| リストには、最後に `_list` をつける | `kudamono_list`、`tensuu_list` |
| 数学と同じ1文字の名前も使う | `x`、`y`、`n`、`i`、`a`、`b` |

ローマ字は、**キーボードで打つときと同じつづり**にします。「てんすう」は `tensuu`、「しょうすう」は `shousuu` です。

```python
tensuu_list = [70, 85, 90]
total = 0
for tensuu in tensuu_list:
    total += tensuu
print(total)
```
`tensuu_list` は「点数のリスト」、`tensuu` は「1つ1つの点数」だと、名前を見るだけで分かります。

::: deep プロの世界では英語で書く
仕事でプログラムを書くときは、世界中の人が読めるように、英語で名前をつけるのがふつうです（`price`、`score_list` など）。英語の単語を覚えてきたら、少しずつ英語の名前に挑戦してみよう。大事なのは、**読んだ人が「何が入っているか」すぐ分かる名前**にすることです。
:::

## 名前に使えない言葉
`if`・`for`・`while`・`def` など、**Pythonの文法で使う言葉**は、名前にできません。

::: deep 名前に使えない言葉の一覧
次の言葉は、Pythonの決まった言葉（**予約語**）なので、名前には使えません。

| 言葉 | 読み方 | 言葉 | 読み方 |
| --- | --- | --- | --- |
| `if` | イフ | `for` | フォー |
| `elif` | エルイフ | `while` | ホワイル |
| `else` | エルス | `in` | イン |
| `def` | デフ | `return` | リターン |
| `True` | トゥルー | `False` | フォールス |
| `and` | アンド | `or` | オア |
| `not` | ノット | `import` | インポート |
| `break` | ブレーク | `continue` | コンティニュー |

```python error
for = 3
```
`for` は[[for]]文の言葉なので、名前にするとエラーになります。
:::

::: deep 使えるけれど、使わない方がいい名前
`print`、`list`、`sum`、`max` など、**Pythonが用意した関数と同じ名前**は、名前に使えてしまいます。でも、使うと、その関数が使えなくなります。

```python error
sum = 10
print(sum([1, 2, 3]))
```
`sum` に `10` を入れたので、`sum` はもう「合計を出す関数」ではなく、ただの数の `10` になってしまいました。合計は `goukei` など、別の名前にしよう。
:::

::: deep 日本語の名前も使える
Pythonでは、`点数 = 80` のように、日本語の名前も使えます。でも、日本語入力のまま書くと、全角の記号やスペースがまざってエラーになりやすいので（[[trouble]]）、この教室ではローマ字で書きます。
:::

@@ list2d
title: 二次元リスト（リストの中のリスト）
type: データ型
chapter: 2
syntax: リスト[たて][よこ]
summary: リストの中にリストを入れたものです。表やゲームのマップのように、たてとよこに並んだデータを表せます。
aliases: 二次元リスト, 二次元配列, 2次元, マップデータ, 表, 入れ子のリスト
reads: list=リスト | for=フォー
group: 必要になったら
--
## リストの中に、リスト
リストの中身には、リストも入れられます。

```python
hyou = [
    [1, 2, 3],
    [4, 5, 6],
]
print(hyou[0])
print(hyou[1][2])
```
`hyou[0]` は1行目のリスト `[1, 2, 3]`、`hyou[1][2]` は「2行目（番号1）の、3つ目（番号2）」で `6` です。

| | `[0]` | `[1]` | `[2]` |
| --- | --- | --- | --- |
| `hyou[0]` | 1 | 2 | 3 |
| `hyou[1]` | 4 | 5 | 6 |

::: point
`リスト[たて][よこ]` の順番です。先に「何行目か」、次に「何列目か」。座標の `(x, y)` とは**逆**なので注意しよう。
:::

## 全部を順番に使う（二重ループ）
```python
hyou = [
    [1, 2, 3],
    [4, 5, 6],
]
for gyou in hyou:
    for kazu in gyou:
        print(kazu, end=" ")
    print()
```
外側の `for` で1行ずつ取り出して、内側の `for` でその行の中身を1つずつ取り出しています（[[for]]）。

## ゲームのマップに使う
文字を並べると、ゲームのマップも作れます。`#` を壁、`.` を通れる場所とします。

```python
mappu = [
    "#####",
    "#...#",
    "#.#.#",
    "#####",
]
print(mappu[2][2])
print(mappu[1][1])
```
文字列も、リストと同じように番号で1文字ずつ取り出せるので（[[str]]）、文字列のリストは二次元リストのように使えます。`mappu[2][2]` は「3行目の3文字目」で、壁の `#` です。

マップを画面に描いたり、壁にぶつかったか調べたりする方法は、[[game-map]]で学びます。

title: タプル
type: データ型
chapter: 2
syntax: (値1, 値2)
summary: 中身を変えられないリストのようなものです。( ) で書きます。座標の (x, y) のように、組にしておきたい値に使います。
aliases: tuple, 組, ( )
reads: tuple=タプル
group: 必要になったら
--
## 書き方
```python
basho = (80, 60)
print(basho)
print(basho[0])
print(basho[1])
```
値を `( )` で囲んで、`,` で区切ります。取り出し方は、リストと同じです（[[list-index]]）。

## リストとのちがい：中身を変えられない
```python error
basho = (80, 60)
basho[0] = 100
```
タプルは、作ったあとで中身を変えられません。「変わってはいけない値」をタプルにしておくと、うっかり書き換えるのを防げます。

| | リスト | タプル |
| --- | --- | --- |
| 書き方 | `[1, 2]` | `(1, 2)` |
| 中身を変える | できる | できない |
| `append` で足す | できる | できない |

## まとめて取り出す
```python
basho = (80, 60)
x, y = basho
print(x, y)
```
タプルの中身を、左の変数に順番に入れます。

関数で `return 80, 60` のように2つの値を返したときも、じつはタプルになっています（[[return]]）。

```python
def ichi():
    return 80, 60


kekka = ichi()
print(kekka)
print(type(kekka))
```

@@ dict
title: 辞書（dict）
type: データ型
chapter: 2
syntax: {キー: 値}
summary: 「名前（キー）」と「値」をセットにして入れておく入れ物です。番号ではなく、名前で取り出せます。
aliases: dict, ディクショナリ, 辞書, キー, 連想配列
reads: dict=ディクト | key=キー | value=バリュー
group: 必要になったら
--
## 書き方
```python
tensuu = {"国語": 80, "数学": 95, "英語": 72}
print(tensuu["数学"])
```
`{ }` で囲んで、`キー: 値` のセットを `,` で区切ります。取り出すときは、`[ ]` の中に**キー**を書きます。

## リストとのちがい
| | リスト | 辞書 |
| --- | --- | --- |
| 書き方 | `[80, 95, 72]` | `{"国語": 80, "数学": 95}` |
| 取り出し方 | 番号で `[1]` | キーで `["数学"]` |
| 向いていること | 順番に並んだもの | 名前で呼びたいもの |

「数学の点数は、何番目だっけ？」と迷わずに、名前でそのまま取り出せるのが、辞書の良いところです。

## 書き換える・増やす
```python
tensuu = {"国語": 80, "数学": 95}
tensuu["国語"] = 85
tensuu["理科"] = 90
print(tensuu)
```
すでにあるキーなら書き換え、まだないキーなら新しく増えます。

## 全部を順番に使う
```python
tensuu = {"国語": 80, "数学": 95, "英語": 72}
for kamoku in tensuu:
    print(kamoku, tensuu[kamoku])
```
[[for]]で回すと、キーが1つずつ `kamoku` に入ります。

::: stuck
ないキーを取り出そうとすると、`KeyError` になります（[[error]]）。

```python error
tensuu = {"国語": 80}
print(tensuu["数学"])
```
キーのつづりがまちがっていないか確かめよう。
:::

::: deep ゲームでの使い方
キャラクターの情報を、1つの辞書にまとめておけます。

```python
chara = {"x": 40, "y": 60, "hp": 3}
chara["x"] = chara["x"] + 2
print(chara)
```
変数を `chara_x`、`chara_y`、`chara_hp` と3つ作るかわりに、1つの辞書にまとめています。
:::

@@ bool
title: 真偽値（bool）
type: データ型
chapter: 2
syntax: True / False
summary: True（正しい）と False（間違い）の2つだけの値です。条件分岐で使います。
reads: bool=ブール | True=トゥルー | False=フォールス
group: 必要になったら
--
::: scratch
Scratchの、角がとがった六角形のブロック（〈（ ）>（ ）〉など）を覚えていますか？ あのブロックの答えが、`True`（はい）か `False`（いいえ）です。
:::

## 2つだけの値
`True`（正しい）と `False`（間違い）のどちらかです。名前の `bool` は、論理学者ブールの名前からきています。

```python
print(5 > 3)
print(5 < 3)
print(type(True))
```
[[comparison]]の結果は、いつも `True` か `False` になります。この値を使って、[[if]]文は「実行するかどうか」を決めます。

## 書き方の注意
先頭は大文字です。小文字の `true` は、Pythonは知らない名前なので[[error]]になります。

```python error
print(true)
```

::: deep 他の値も、True か False として扱われる
`0`、空の文字 `""`、空のリスト `[]` は `False` として、それ以外は `True` として扱われます。

```python
print(bool(0))
print(bool(1))
print(bool(""))
print(bool("a"))
```
:::
