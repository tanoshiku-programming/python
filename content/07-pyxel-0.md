## Pyxel 2 のゴール
Pyxel 1で、画面を出せるようになりました。Pyxel 2では、その画面に**描いて**、**動かして**、**操作**できるようにします。これができれば、ゲームの形が作れます。

### 読むページ（この順番で）
1. [[pyxel-text]]：文字を表示する
2. [[shapes]]：四角・円・線などの図形を描く
3. [[pyxel-var]]：変数で、図形を動かす（ここがいちばん大事）
4. [[pyxel-key]]：キーで操作する
5. [[pyxel-mouse]]：マウスで操作する
6. [[pyxel-jp]]：日本語を表示する（使いたくなったら）

::: point
**`update` で変数を変えて、`draw` で、その変数を使って描く。** Pyxel 2のページは、全部この形の練習です。
:::

## Pyxel 3 のゴール
ここまでに学んだ「描く・動かす・操作する」と、Pythonの基本（変数・if・リストなど）を組み合わせて、**1つの作品**を作ります。どれも、新しい命令はほとんど出てきません。今までの組み合わせだけで作れます。

### 読むページ（この順番で）
1. [[app-fortune]]：占いアプリ（マウス・リスト・random）
2. [[app-timer]]：ストップウォッチ（キー・割り算・True/False）
3. [[game-catch]]：ゲーム「ほしキャッチ」（ここまでの総まとめ）
4. [[game-scene]]：タイトル画面と結果画面をつける
5. [[game-list]]：たくさんのものを動かす

::: point
作品を作るときは、いきなりプログラムを書かずに、**「何が必要か」を日本語で書き出す**ところから始めます。各ページの「設計図」を見てみよう。
:::

## Pyxel 4 のゴール
図形のかわりに**ドット絵**を出したり、**効果音**を鳴らしたりすると、作品が一気にゲームらしくなります。最後に、できた作品を**友だちに配る**方法も学びます。

### 読むページ（この順番で）
1. [[object]]：`pyxel.sounds[0].set()` のように、ドットが2回出てくるわけ
2. [[game-image]]：ドット絵を出して、歩かせる
3. [[game-sound]]：効果音を鳴らす
4. [[pyxel-editor]]：Pyxel Editorで、自分の絵や音を作る
5. [[pyxres-game]]：Editorで作った絵と音を、ゲームで使う
6. [[game-package]]：作品を配る（ブラウザで遊べるようにする）

::: point
1つ目の「ドットが2回出てくるわけ」を先に読んでおくと、そのあとのページが、ぐっと読みやすくなります。
:::

## Pyxel 5 の使い方
ここにあるのは、ゲームでよく使う**技**です。**全部を順番に読む必要はありません。** 作りたいゲームに合わせて、必要なページを選んで読もう。

### 作りたいゲームで選ぶ
| 作りたいゲーム | 読むとよいページ |
| --- | --- |
| どのゲームでも | [[game-hit]]・[[game-highscore]] |
| シューティング | [[game-shot]]・[[game-enemy]]・[[game-effect]] |
| アクション（横に進む） | [[game-jump]]・[[game-wall]]・[[game-scroll]] |
| 迷路・RPG（マス目を歩く） | [[game-map]]・[[game-wall]] |

### 全部の技
- [[game-hit]]：当たり判定（ぶつかったか調べる）
- [[game-shot]]：弾を撃つ
- [[game-enemy]]：敵を出す
- [[game-scroll]]：スクロール（背景を動かす）
- [[game-map]]：マップを作る
- [[game-jump]]：ジャンプ
- [[game-wall]]：壁にぶつかったら止める
- [[game-effect]]：爆発・画面ゆれ・無敵時間
- [[game-highscore]]：ハイスコアとランキング

::: point
技のページの例は、短く作ってあります。自分のゲームに入れるときは、**例をそのまま写さずに**、「何をしているか」を読んでから、自分のゲームに合わせて書こう。
:::
