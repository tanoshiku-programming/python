## この章のゴール
Pythonのプログラムは、だいたい「入力 → 処理 → 出力」でできています。この章では、それを3つのステップに分けて、1つずつできるようにします。

| ステップ | できるようになること | 出てくる言葉 |
| --- | --- | --- |
| 1 表示する | 画面に文字や数を出す | [[print]]、[[comment]] |
| 2 計算する | 足し算やかけ算をする | [[operator]]、[[int]]、[[float]]、[[math-func]] |
| 3 入力する | キーボードから受け取って使う | [[input]]、[[str]]、[[typeconv]]、[[fstring]] |

エラーが出たら、[[error]]で読み方を確かめよう。

## まず、表示してみる
```python
print("こんにちは")
print(1 + 2)
```
文字は `"` で囲みます（[[str]]）。囲まない `1 + 2` は計算されて `3` になります。プログラムの中にメモを残したいときは、[[comment]]を使います。

::: scratch
`print("こんにちは")` は、Scratchの「（こんにちは）と言う」ブロックに近い命令です。ちがうのは、ネコのふきだしではなく、画面（ターミナル）に文字が出ることです。
:::

## 計算してみる
```python
print(7 + 3)
print(7 * 3)
print(7 / 2)
```
`*` がかけ算、`/` が割り算です（[[operator]]）。`7` のような小数点のない数を**整数**（[[int]]）、`3.5` のような小数点のある数を**小数**（[[float]]）といいます。

## 入力を受け取る
```python in=はなこ
name = input("名前を入力してください：")
print("こんにちは、" + name + "さん")
```
`name` のように、値に名前をつけたものを[[variable]]といいます（詳しくは第2章）。

::: scratch
`input()` は、Scratchの「（〇〇）と聞いて待つ」ブロックです。Scratchでは答えが「答え」ブロックに入りましたが、Pythonでは `name = input(…)` のように、**自分で決めた名前の変数**に入れます。
:::

## 入力した数で計算してみる
```python in=8
n = input("数を入力：")
print(n * 3)
```
`24` ではなく `888` になりました。`input()` で受け取ったものは、数字に見えても**文字**として扱われるからです。計算したいときは、[[typeconv]]で数に変えます。

```python in=8
n = int(input("数を入力："))
print(n * 3)
```
これで `24` になりました。

::: point
`input()` の結果は、いつも文字列（[[str]]）。数として使うときは `int()` で包む。
:::

## 覚えておく3つのデータ型
ここまでに出てきた「整数」「小数」「文字列」のような、値の種類を**データ型**といいます。この章では、この3つを覚えればOKです。

| データ型 | 名前 | 例 |
| --- | --- | --- |
| `int` | 整数（[[int]]） | `10`、`-3` |
| `float` | 小数（[[float]]） | `3.5` |
| `str` | 文字列（[[str]]） | `"こんにちは"`、`"10"` |

`10` と `"10"` は、見た目は似ていても別の型です。だから計算の結果もちがいます。ほかにも、`True` と `False` の型や、リストの型などがあります。知りたい人は[[datatype]]を見てみよう。

## やってみよう
::: try 10年後の年齢
`input()` で今の年齢を聞いて、「10年後は○○才です」と表示するプログラムを作ってみましょう。
:::
::: answer
```python in=12
nenrei = int(input("今の年齢は？"))
print("10年後は" + str(nenrei + 10) + "才です")
```
`nenrei + 10` は数なので、文字とつなぐときは `str()` で文字に変えます。もっと簡単な書き方は[[fstring]]です。
:::

::: try 合計金額
値段と個数を聞いて、合計金額を表示しましょう。
:::
::: answer
```python in=120|3
nedan = int(input("値段は？"))
count = int(input("いくつ買いますか？"))
print(f"合計は{nedan * count}円です")
```
:::

## 使い方
```python
print("Hello")
print(100)

```
かっこの中に書いたものが画面に表示されます。文字は `"` か `'` で囲みます（[[str]]）。数や計算は、囲まずにそのまま書きます。

## いくつも並べる
```python
print("点数は", 80, "点です")
```
カンマ `,` で区切ると、間に空白が入って並んで表示されます。

## 改行しない
`print()` は、表示したあとに自動で改行します。改行したくないときは `end=""` を足します。

```python
print("あ", end="")
print("い")
```

::: deep 区切りの文字を変える（sep）
カンマで並べたときの区切りは、ふつう空白です。`sep` で変えられます。

```python
print("2026", "10", "17", sep="/")
```
:::

::: deep >>> の画面では、print がなくても表示される？
IDLE を開いたときに出る `>>>` の画面（シェル）では、`1 + 2` と打つだけで `3` と表示されます。でも、ファイルに書いたプログラムでは、表示したいものは必ず `print()` で表示します。詳しくは[[shell]]を見よう。
:::

::: stuck
文字を `"` で囲み忘れると、Pythonは「そんな名前は知らない」と考えて[[error]]を出します。

```python error
print(こんにちは)
```
`print("こんにちは")` と、`"` で囲みましょう。
:::

## 書き方
`#` から行の終わりまでが、コメントになります。

```python
print("A")
```

## 計算の記号
| 記号 | 意味 | 例 | 答え |
| --- | --- | --- | --- |
| `+` | 足し算 | `7 + 2` | `9` |
| `-` | 引き算 | `7 - 2` | `5` |

| `/` | 割り算（答えは小数） | `7 / 2` | `3.5` |
| `//` | 割り算の商（整数） | `7 // 2` | `3` |
| `%` | 割り算の余り | `7 % 2` | `1` |
| `**` | べき乗 | `7 ** 2` | `49` |

```python
print(7 // 2)
print(7 % 2)
print(2 ** 10)
```
`/` の答えは[[float]]、`//` の答えは[[int]]になります。

## 計算の順番
算数と同じで、かけ算・割り算が先です。かっこで順番を変えられます。

```python
print(1 + 2 * 3)
print((1 + 2) * 3)
```

::: deep 余り（%）の使い道
`% 2` の答えが `0` なら偶数、`1` なら奇数です。[[comparison]]の `==` と組み合わせて、偶数かどうかを調べられます。

```python
n = 10
print(n % 2 == 0)
```
:::

## 整数とは

```python
print(10 + 3)
```

`type()` を使うと、値の[[datatype]]が分かります。

```python
print(type(10))
```

`10` は `int`、`"10"` は `str`（[[str]]）です。

`int()` で、文字を整数に変えられます（[[typeconv]]）。

```python
print(int("42") + 1)
print(int(3.9))
```
小数（[[float]]）を `int()` に入れると、小数点以下が切り捨てられます。

::: deep とても大きな数も使える

## 書き方
小数点をつけて書きます。名前の `float` は「浮動小数点数」の英語の頭文字からきています。

```python
print(type(3.14))
print(2.5 * 2)
```
`2.5 * 2` の答えは `5` ではなく `5.0` です。小数が入った計算の答えは、いつも小数になります。

## 割り算の答えは小数
```python
print(10 / 4)
print(10 / 2)
```
`10 / 2` は割り切れますが、答えは `5.0` です。整数で答えがほしいときは、`//`（[[operator]]）を使います。

## 整える
```python
print(int(3.9))
print(round(3.14159, 2))
```
`int()` は切り捨て、`round(数, 桁数)` は四捨五入です。

::: deep 0.1 + 0.2 が 0.3 にならない
```python
print(0.1 + 0.2)
```
コンピュータは数を2進数で覚えているため、0.1 のような小数をぴったり表せません。ごくわずかなズレが出ます。お金の計算などでは、整数（[[int]]）にそろえて計算するのがコツです。
:::

## 4つの関数
| 関数 | すること | 例 | 答え |
| --- | --- | --- | --- |
| `abs(数)` | 絶対値（マイナスを取る） | `abs(-5)` | `5` |
| `max(a, b, …)` | いちばん大きい数 | `max(3, 8, 5)` | `8` |
| `min(a, b, …)` | いちばん小さい数 | `min(3, 8, 5)` | `3` |
| `round(数, 桁)` | 四捨五入 | `round(3.14159, 2)` | `3.14` |

```python
print(abs(-5))
print(max(3, 8, 5))
print(min(3, 8, 5))
print(round(3.14159, 2))
```

## abs：どれだけはなれているか
`abs` は、マイナスの数をプラスにします（プラスの数はそのまま）。「ちがいの大きさ」だけを知りたいときに使います。

```python
a = 3
b = 10
print(abs(a - b))
print(abs(b - a))
```
引く順番が逆でも、答えは同じ `7` です。ゲームでは「キャラクターどうしが、どれだけ近いか」を調べるときに使います（[[game-hit]]）。

## max と min：はみ出さないようにする
```python
x = 170
x = min(x, 152)
print(x)
x = -4
x = max(x, 0)
print(x)
```
`min(x, 152)` は「152 より大きくならないようにする」、`max(x, 0)` は「0 より小さくならないようにする」という使い方です。ゲームで、キャラクターが画面からはみ出さないようにするときに使います（[[pyxel-key]]）。リストの中のいちばん大きい数を調べるときにも使えます（[[list]]）。

::: deep round(2.5) が 3 にならない？
```python
print(round(2.5))
print(round(3.5))
```
ちょうど `.5` のときは、近い**偶数**のほうに丸めるのが、Pythonのきまりです。ふだんの計算では、あまり気にしなくて大丈夫です。
:::

`len()` は、長さ（文字の数）を調べる関数です。

@@ fstring
title: f文字列
type: 書き方
chapter: 1
syntax: f"こんにちは、{name}さん"
summary: 文字列の中に { } で変数や計算結果をはめこめる書き方です。
reads: f=エフ | { }=波かっこ | :.2f=コロン ドット2エフ
group: ステップ3 入力する
--
## 書き方のかたち
::: tpl f文字列の書き方
f"〔文字〕{〔変数や計算〕}〔文字〕"

| 〔変数や計算〕 | { } の中に書くと、その値が文の中に入る |
| 〔文字〕 | そのまま表示される文章 |
:::

## 書き方
文字列の前に `f` をつけて、はめこみたい場所を `{ }` で囲みます。

```python
name = "はなこ"
nenrei = 12
print(f"{name}さんは{nenrei}才です")
print(f"来年は{nenrei + 1}才です")
```
`{ }` の中には、[[variable]]だけでなく計算も書けます。

## f文字列を使わないと
`+` でつなぐと、数を文字に変えなければいけません（[[typeconv]]）。

```python
name = "はなこ"
nenrei = 12
print(name + "さんは" + str(nenrei) + "才です")
```
f文字列のほうが、短くて読みやすいです。

::: deep 小数点の桁数や、3桁区切り
`{ }` の中で `:` のあとに書くと、見た目を整えられます。

```python
x = 3.14159
n = 1234567
print(f"{x:.2f}")
print(f"{n:,}")
```
`.2f` は「小数点以下2桁」、`,` は「3桁ごとに区切り」です。
:::

@@ error

summary: プログラムに間違いがあるときに出るメッセージです。最後の行に原因が書いてあります。
reads: NameError=ネームエラー | TypeError=タイプエラー | ValueError=バリューエラー | SyntaxError=シンタックスエラー | ZeroDivisionError=ゼロディビジョンエラー | IndexError=インデックスエラー

## エラーは「ヒント」
エラーが出ると、びっくりします。でもエラーメッセージは、間違いの場所と理由を教えてくれる、ヒントです。

## 読む順番
```python error
kazu_list = [10, 20, 30]
print(kazu_list[3])
```
1. **最後の行**を読む：`IndexError: list index out of range`（番号が範囲の外）
2. **`line 2`** を見る：2行目で起きた
3. その行を見直す：リストは3つなのに、`kazu_list[3]` を取り出そうとしている（[[list-index]]）

## よく見るエラー
| エラー | 意味 | よくある原因 |
| --- | --- | --- |
| `SyntaxError` | 書き方がまちがっている | `:` やかっこの書き忘れ |
| `NameError` | 知らない名前が出てきた | 変数のつづりミス、`"` の書き忘れ |
| `TypeError` | 型が合わない | 文字と数を足している（[[datatype]]） |
| `ValueError` | 値を変換できない | `int("abc")`（[[typeconv]]） |
| `IndexError` | 番号が範囲の外 | [[list]]の長さを超えた |

## データ型とは
プログラムで使う値には、種類があります。この種類をデータ型といいます。

| 型 | 名前 | 例 |
| --- | --- | --- |
| `int` | [[int]] | `10`、`-3` |
| `float` | [[float]] | `3.14` |
| `str` | [[str]] | `"Python"` |
| `bool` | [[bool]] | `True`、`False` |
| `list` | [[list]] | `[1, 2, 3]` |

## 型を調べる
`type()` で調べられます。

```python
print(type(10))
print(type(3.14))
print(type("Python"))
print(type(True))
print(type([1, 2, 3]))
```

## 型がちがうと、できることもちがう
数どうしは足せますが、数と文字は足せません。

```python error
print("3" + 4)
```
「文字列 `"3"` に、数 `4` はつなげられない」という[[error]]です。直し方は[[typeconv]]を見てください。

::: point
プログラムの途中で「これは何の型だっけ？」と迷ったら、`print(type(変数))` で調べられます。
:::
